A small, modern language and its editor. 一门小巧、现代的语言，以及它的编辑器。

NanoX is an easy-to-learn programming language and an IDE-style terminal editor, built from scratch in C++17. NanoX 是一门易学的编程语言，也是一个 IDE 风格的终端编辑器，完全使用 C++17 从零构建。

Why NanoX为什么选择 NanoX

Small, readable, built in the open小巧、易读、公开构建

From-scratch lexer从零实现的词法分析器

Every token carries a precise line:column location. Zero-copy lexemes and full error recovery — diagnostics never silently skip a problem. 每个记号都带有精确的 行:列 位置。零拷贝词素与完整的错误恢复，诊断信息绝不悄悄跳过问题。

Three editing modes三种编辑模式

Vim, GNU nano and a Hybrid mode share one keymap layer. Cycle with F8 or :set mode. Vim、GNU nano 与混合模式共用一套快捷键层。用 F8 或 :set mode 切换。

IDE-style terminal UIIDE 风格的终端界面

Project explorer, multi-file tabs, an OUTPUT panel and a lexer-level REPL — all in the terminal. 项目浏览器、多文件标签、OUTPUT 面板与词法级 REPL — 全部运行在终端里。

UTF-8 aware layout支持 UTF-8 的布局

A compact East Asian width table keeps every frame aligned, even with CJK file names, paths and source code. 内置紧凑的东亚字符宽度表，即使文件名、路径与源码包含中文，边框也始终对齐。

Cross-platform跨平台

Linux, macOS and Windows, with dedicated POSIX and Windows terminal backends behind one interface. 支持 Linux、macOS 与 Windows，统一的接口背后是各自的 POSIX 与 Windows 终端实现。

Ready to package开箱即用的打包

TGZ and ZIP everywhere, a .deb on Linux, plus Homebrew, Scoop and AUR manifests. 各平台生成 TGZ 与 ZIP，Linux 上还有 .deb，并附带 Homebrew、Scoop 与 AUR 清单。

The language语言

Familiar, tiny, and easy to read熟悉、精简、易于阅读

The first milestone is a classic compiler pipeline: Lexer → Parser → AST → Interpreter. LLVM code generation is explicitly out of scope until the interpreter is solid. 第一个里程碑是一条经典的编译管线：词法分析 → 语法分析 → AST → 解释器。在解释器稳定之前，LLVM 代码生成明确不在范围内。

  • Integers, floats, strings and booleans整数、浮点数、字符串与布尔值

  • Line and block comments行注释与块注释

Get started开始使用

Build it in three commands三条命令即可构建

Requirements: CMake 3.20+ and any C++17 compiler. If several compilers are installed, pick one explicitly with -DCMAKE_CXX_COMPILER. 环境要求：CMake 3.20+ 以及任意 C++17 编译器。若安装了多个编译器，可用 -DCMAKE_CXX_COMPILER 明确指定。

See the roadmap查看路线图
shell
# configure & build
cmake -S . -B build
cmake --build build

# run the tests
ctest --test-dir build --output-on-failure

# launch the editor
./build/examples/nanox examples/hello.nx
